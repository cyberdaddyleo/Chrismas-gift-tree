# 圣诞礼物树 · Chrismas Gift Tree

把一张演唱会门票、一句祝福或一份店内奖品挂上 3D 圣诞树。收礼人可以用鼠标点开相框，也可以对着摄像头捏合手指，把礼物拿到眼前。切到盲盒模式后，所有相框都会变成问号，按奖池里的份数随机开奖。

## 直接玩

1. 在 GitHub 打开仓库里的离线成品，点击文件页右上方的下载图标（Download raw file），把约 14 MB 的 HTML 保存到电脑。[圣诞礼物树.html](./圣诞礼物树.html)
2. 用桌面版 Chrome 或 Edge 打开下载的文件。代码、字体和手势模型都已内嵌，打开后可离线游玩。
3. 选 **用鼠标打开**，点树上的相框看第一份礼物。想体验手势，选 **用手势打开** 并允许使用摄像头。手部动作在本机识别。

## 可以怎样玩

| 想做什么 | 从哪里开始 |
| --- | --- |
| 给一个人送祝福 | 点「编辑祝福」，写下收礼人、祝福语和署名。可以选内置插画，也可以把自己的礼物照片挂上树。 |
| 办一场圣诞抽奖 | 点右侧「盲盒」→「设置奖池」，填奖品份数，再点底部「抽一个」。支持抽中扣减、加入「谢谢参与」和查看抽奖记录。 |
| 换个场景 | 右侧「场景」提供雪原、林间小屋、雪夜小镇和壁炉客厅。双击空白处，可以看整棵树散成星河。 |

要把定制好的树作为一个文件发给别人，请在离线成品里点 **生成专属文件**。按键、手势、开奖规则和导出步骤见 [玩法说明](./玩法说明.md)。

## 运行源码

从 GitHub 用 **Code → Download ZIP** 下载并解压整个项目，或用 Git 克隆仓库。在含有 `index.html` 的仓库根目录执行以下命令。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

用浏览器打开 `http://localhost:8000/`。源码入口按 ES 模块加载同目录的脚本和资源，编辑后刷新即可。这个版本的「复制分享链接」会把祝福、场景、版本及选中的预设礼物放入网址。想让别人打开这个链接，请先把项目部署到对方能访问的 HTTPS 地址。自定义照片和奖池份数通过离线版的「生成专属文件」分享。

## 构建离线成品

安装 Node.js 和 npm 后，在仓库根目录执行以下命令。

```sh
cd build
npm install --no-save three@0.185.0 esbuild@0.25.10
node build.mjs
```

脚本会重新生成仓库根目录的 `圣诞礼物树.html`。需要保留原成品时，可以把最后一条命令改为 `node build.mjs ../圣诞礼物树-新版.html`。

| 源码位置 | 内容 |
| --- | --- |
| `index.html` | 页面结构、样式、启动卡片和设置面板 |
| `js/main.js` | 交互、奖池、浏览器存储和专属文件导出 |
| `js/gifts.js` | 男生版、女生版和宝宝版的预设礼物与插画 |
| `js/tree.js`、`js/scenes.js`、`js/fx.js` | 圣诞树、四个场景和粒子特效 |
| `js/gesture.js`、`js/audio.js` | MediaPipe 手势识别、音乐和音效 |
| `lib/`、`models/` | Three.js、MediaPipe 运行库、WebAssembly 和手部模型 |
| `build/build.mjs` | 合并脚本、压缩并内嵌资源，输出单文件 HTML |
